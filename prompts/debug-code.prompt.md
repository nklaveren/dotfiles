## Debugging Process

### 1. Issue Analysis
- Identify the specific problem or error
- Understand the expected vs actual behavior
- Analyze error messages and stack traces
- Examine the code context and flow

### 2. Root Cause Investigation
- Trace through the code execution path
- Identify potential causes (logic errors, edge cases, race conditions)
- Check for common pitfalls and anti-patterns
- Analyze variable states and data flow

### 3. Debugging Techniques
- Add strategic console.log statements
- Use debugger breakpoints effectively
- Implement proper error handling
- Add input validation and guards
- Use TypeScript for better type safety

### 4. Testing and Validation
- Create test cases to reproduce the issue
- Verify the fix works for all scenarios
- Check for regressions in related functionality
- Test edge cases and boundary conditions

## Common Issue Categories

### JavaScript/TypeScript Issues
- Undefined variables and null pointer exceptions
- Scope and closure problems
- Async/await and Promise handling
- Type mismatches and casting issues
- Memory leaks and performance problems

### React Issues
- Component lifecycle problems
- State management issues
- Hook dependency problems
- Re-rendering issues
- Event handling problems

### API and Network Issues
- Request/response handling
- CORS and authentication problems
- Error handling and retry logic
- Data parsing and validation
- Race conditions in async operations

### Logic and Algorithm Issues
- Off-by-one errors
- Infinite loops and recursion
- Incorrect conditional logic
- Data structure misuse
- Performance bottlenecks

## Solution Format
1. **Problem Description**: Clear explanation of the issue
2. **Root Cause**: Detailed analysis of why the problem occurs
3. **Solution**: Step-by-step fix with code examples
4. **Prevention**: How to avoid similar issues in the future
5. **Testing**: Recommended tests to verify the fix

Please provide a comprehensive debugging analysis and solution.
