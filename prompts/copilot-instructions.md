# Copilot Instructions

## Project Context
This is a dotfiles repository containing configuration files for development environments including VS Code settings, shell configurations, and automation scripts.

## Coding Standards

### General Principles
- Write clear, self-documenting code
- Use consistent naming conventions
- Add comments for complex logic
- Follow the principle of least surprise
- Keep configurations maintainable and portable

### File Organization
- Group related configurations together
- Use meaningful file and directory names
- Keep configurations modular and reusable
- Document any non-obvious configuration choices

### Shell Scripts
- Use bash for portability
- Include proper error handling
- Add usage documentation
- Make scripts executable and portable
- Use functions for reusable code blocks

### JSON/JSONC Configuration
- Use consistent indentation (2 spaces)
- Group related settings together
- Add comments to explain complex configurations
- Use meaningful property names
- Validate JSON syntax

### Documentation
- Include README files for complex configurations
- Document installation and setup procedures
- Explain dependencies and requirements
- Provide examples and usage instructions

## Best Practices
- Test configurations on clean environments
- Use version control for all changes
- Keep sensitive information out of dotfiles
- Make configurations cross-platform when possible
- Use environment variables for system-specific values
